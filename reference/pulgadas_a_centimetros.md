# Convierte pulgadas a centimetros

Convierte pulgadas a centimetros

## Usage

``` r
pulgadas_a_centimetros(pulgadas)
```

## Arguments

- pulgadas:

  Numero (o vector numerico) con medidas en pulgadas.

## Value

Un numero (o vector) con la medida en centimetros.

## Examples

``` r
pulgadas_a_centimetros(10)
#> [1] 25.4
```
